# Hotel Booking Management System

## Overview
A command-line Python application for managing hotel rooms, customers, bookings, billing, and reports.

## Features
* Room and customer management
* Booking and cancellation tracking
* Automated bill generation
* Comprehensive hotel reports
* Local CSV data storage
* Robust input validation

## Technologies
* Python 3
* CSV Module
* Git / GitHub

## Project Structure
```text
Hotel-Booking-Management-System/
├── src/
├── data/
├── tests/
├── docs/
├── README.md
├── statement.md
└── requirements.txt
```

## How to Run
1. Clone the repository and navigate to the project folder.
2. Make sure Python 3 is installed.
3. Run the application:
   ```bash
   python src/main.py
   ```

## Testing & Data Storage
* **Testing:** Run and verify features using the interactive command-line interface.
* **Data Storage:** Persistent data is saved automatically as CSV files inside the `data/` directory.
