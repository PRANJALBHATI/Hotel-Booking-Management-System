# Hotel Booking Management System

## Problem Statement

Managing hotel rooms, customer information, bookings, and billing manually can be time-consuming and may lead to errors. A simple computerized system can help organize these activities and make the booking process easier.

The Hotel Booking Management System is a command-line Python application designed to manage hotel rooms, customer information, room bookings, cancellations, billing, and basic hotel reports.

## Scope of the Project

The project covers the basic operations required to manage a small hotel's booking system.

The system allows users to:

- View available and occupied rooms
- Add, update, and delete room information
- Add, update, and delete customer information
- Create and cancel bookings
- View booking records
- Generate bills based on room price and number of nights
- View hotel summary reports
- View currently available rooms
- Store information using CSV files

The project is designed as a command-line application and does not include online payment processing or online booking.

## Target Users

The primary target users are:

- Hotel reception staff
- Small hotel administrators
- Hotel booking operators

The system can help these users manage basic hotel operations through a simple command-line interface.

## High-Level Features

### 1. Room Management

The system allows users to:

- View rooms
- Add rooms
- Update room information
- Delete rooms
- Track room availability

### 2. Customer Management

The system allows users to:

- Add customer details
- View customer records
- Update customer information
- Delete customer records

### 3. Booking Management

The system allows users to:

- Create bookings
- View bookings
- Cancel bookings
- Check room availability
- Associate bookings with customers

### 4. Billing

The system calculates the total room cost based on:

- Room price per night
- Number of nights

### 5. Reports

The system provides:

- Hotel summary
- Total rooms
- Available rooms
- Occupied rooms
- Total customers
- Active bookings
- Cancelled bookings
- List of available rooms
